## Colour System

**Red (`--accent`)**: CTAs, buttons, key emphasis, title hover states, "Read more" links, blockquote borders
**Gold (`--gold`)**: Section labels (uppercase tags), icons, metadata, category badges, "Back to" links, bullet dots, footer text, founder roles

Gold shade: `38 58% 42%` — rich burnished tone
Red shade: `0 72% 48%` — prominent accent
